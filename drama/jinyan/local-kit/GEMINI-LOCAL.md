# 《谨言》生产流程 · Gemini 出图 + 即梦出视频

**SS 定稿流程：** 静图 Gemini → 视频即梦 Seedance → 合成剪映

---

## 流水线（每集重复）

```
Gemini 生静图（9:16）
        ↓
下载 PNG → 即梦「图生视频」Seedance 2.0 + 人物锁定
        ↓
剪映：8 段 mp4 + 配音 + 字幕 + BGM → 导出 60 秒
```

| 环节 | 工具 | 登录 |
|---|---|---|
| 静图 / 锚定 | **Gemini**（Chrome） | Google |
| 图生视频 | **即梦** jimeng.jianying.com | 手机/抖音 |
| 合成 | **剪映** | — |

## 第三步 · 即梦图生视频（每镜）

1. 打开 https://jimeng.jianying.com → 登录
2. **图生视频** → 模型 **Seedance 2.0**
3. 上传对应 `E01_S0X.png`
4. 开启 **人物锁定**（有人脸的镜 S01/S03/**S04**/S05/S06/S07/S08 必开）
5. 时长按表；**运镜只写动作，别重复画面描述**

| 镜 | 时长 | 即梦运镜提示词 |
|---|---|---|
| S01 | 4s | 固定机位，门缝裁切，女人轻微转头，侧逆光 |
| S02 | 6s | 固定机位，屏幕微亮，办公室冷光 |
| S03 | 7s | 缓慢推近，男人抬头 |
| S04 | 6s | 固定机位，侧脸，监视器光闪烁 |
| S05 | 7s | 固定机位，拇指悬停屏幕 |
| S06 | 6s | 固定机位，男人停筷 |
| S07 | 8s | 固定机位，双机震动 |
| S08 | 8s | 宋推近震惊 4s + 温固定 4s |

6. 导出 → `E01/videos/E01_S01.mp4` … `S08.mp4`

**即梦注意：**
- Gemini 图已是 9:16，上传后确认比例不变形
- 人脸镜若跳戏：即梦重新生成 2 次，或回 Gemini 修静图再导入
- 即梦**不需要**再文生图；只走「图生视频」

## 第四步 · 剪映合成 E1

1. 按 S01→S08 导入 **即梦 mp4**
2. AI 配音 + 台词（见下）
3. S02 叠字「稿件已撤回」
4. 字幕；集末黑屏「下集：门岗敬礼，总编还在吼」
5. 导出 `export/JY_E01_撤稿.mp4`（1080×1920，58–62s）

## 常见问题

| 问题 | 处理 |
|---|---|
| Gemini 脸好、即梦视频脸崩 | 即梦开人物锁定；静图用正脸清晰的；或缩短时长 3–5s |
| 即梦和 Gemini 色调不一致 | Gemini 侧光统一；即梦运镜别写改光线 |
| S02 要不要人物 | **不要**，屏幕+VO 即可 |
| 即梦还要角色管理吗 | 图生视频可不用；有人脸镜开「人物锁定」即可 |
