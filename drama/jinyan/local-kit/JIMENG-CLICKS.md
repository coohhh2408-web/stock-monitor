# 即梦点击路径（《谨言》）

## 入口
- 官网：https://jimeng.jianying.com
- 创作页：https://jimeng.jianying.com/ai-tool/home

## A. 角色锚定（最先做）

```
首页 → 图片生成 / 图片 5.0 Pro
→ 比例 9:16
→ 粘贴 prompts/00-characters.md 里对应角色
→ 生成 2–4 张 → 选 1 张
→ 【角色管理】→ 上传/保存 → 命名：谷锦丹、温清遥、宋谨言、顾正纲、章世藩
→ 后续提示词用 @角色名 或「参考图」绑定
```

## B. 分镜静图（每镜）

```
图片生成 → 9:16 → 写实
→ 粘贴 E01-shots.md 该镜正向提示词
→ 反向词（每张必加）：
   五官扭曲、手脚畸形、模糊、水印、文字、Logo、露点、深V露沟、开衩过高、卡通
→ 出 2–4 张择优 → 保存为 E01_S01.png …
```

## C. 图生视频（Seedance）

```
图生视频 → 模型 Seedance 2.0
→ 上传该镜静图
→ 开启「人物锁定」/ 全能参考
→ 时长：按分镜表（3–10 秒）
→ 运镜词：缓慢推近 / 固定机位 / 低机位跟拍（每镜选 1 个）
→ 导出 E01_S01.mp4 …
```

## D. 剪映合成

```
导入 8 段视频 → 按镜号排序
→ AI 配音（见 ep01-05-jimeng.md 台词）
→ 字幕自动识别 → 关键词加粗
→ 集末 0.5s 黑屏 + 字「下集：门岗敬礼，总编还在吼」
→ 导出 1080×1920，检查 58–62 秒
→ 命名 JY_E01_撤稿.mp4
```

## 常见问题

| 问题 | 处理 |
|---|---|
| 弹出登录 | 必须登录，无法用游客生成 |
| 角色脸跳 | 重新用角色管理 @引用；每镜头部写 `@角色名` |
| 过审不过 | 加「不露点、开衩及膝、仿皮草」；删「性感」「透视」 |
| 靴/丝不像 | 用 COSTUME-MALE35 里 B1–B8 具体款名 |
