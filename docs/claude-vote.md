# Claude（Opus）投票 — 2026-08-27 Cursor 云端

投票针对 `docs/claude-meeting-brief.md` 的 6 个问题。同意的地方不复述，分歧写在第 6 节。

## 1. 商业模式（≤5 句）

Apify 是网页数据的货架：买家是营销、招聘、增长、研究团队和开发者，他们已经有账号和每月免费额度，需要某个站的结构化数据时去 Store 或 Google 搜 `[站点] scraper`。钱走平台：Actor 标 Pay-per-event，用户跑一次平台记账，开发者分约 80%，再从这 80% 里扣掉本次跑的算力和代理。冷启动是选词 + Actor 详情页吃 Google + README 当销售页 + 当天回 issue，不是微信拉人。它租给你的是已有流量、已有收银台、已有信任；代价是每个 Actor 都是永久维护负债，目标站一改版你就掉线。月租 2026-10-01 退市，新 Actor 只能做 PPE。

## 2. 到价提醒谁买单 / 冷启动

买单人是有 A 股持仓、工作日不能在公司亮炒股软件的上班族，卖的是"锁屏也以来电样式响"，付费理由成立。冷启动不成立：没有自带搜索入口（没人搜"来电伪装股价提醒"，搜"股价预警"的被同花顺和券商 App 吸走），15 个熟人是存量不是渠道，¥98 是人情价，一对一获客的边际成本不下降。结论：**有产品、没渠道**，而渠道是这两条线里最贵、最慢、最不可能在 14 天里补上的东西。

## 3. 到价提醒能不能上 Apify

不能。买家不对（货架上的人买数据集，不买单机闹钟），计费方向相反（PPE 按结果收费，而闹钟最值钱的状态是"大部分时候没响"），来电伪装是端上能力带不过去，Store 里也没人搜 price alert。

补一条 Grok 没说的：**连"原料"也不值得上**。A 股/港股行情快照 Actor 会被 Yahoo Finance、Alpha Vantage 之类的免费层直接打死，别在 D1 浪费时间做它。

## 4. 朋友那套成不成立

「找需求 → 快上线 → 营销」在 Apify 上成立，但三个环节都要改一个字：

- 找需求 ≠ 找最火。TikTok/IG 是 Clockworks 的场，他的 $19.56 是从被占的词里漏下来的残量。
- 快上线 ≠ 铺量。17 个 Actor 是 17 份维护负债，第 3 个月会压死一个人；他失败率从 80% 降到 5% 说明他真正的成本花在修，不是在选。
- "AI 不会营销"是误判。在这个平台上营销就是选词、README、PPE 定价、回 issue，这几件 AI 恰好都能做。他缺的是选词判断力，不是渠道能力。

**但我不同意把"选错词"当成唯一解释。** 在被占的词里做二流 Actor 拿到 $27；在没人搜的空位词里做二流 Actor 拿到 $0。空位不等于机会，空位里有一半是"没需求"或"反爬做不动所以没人做"。

## 5. 14 天只做

**Apify。到价提醒工程冻结。**

一句话理由：到价提醒缺渠道，Apify 缺选品；14 天里工程能力只能补选品，补不出渠道。只有 Apify 这条线可能在 14 天内拿到"陌生人付钱"的证据。

## 6. 和 Grok 的分歧（4 条）

### 6.1 反对把 BOSS 直聘当第一个 Actor

Grok 把它列为候选，理由是"有人搜过、货是坏的"。我认为它同时踩了四个坑：

1. 反爬是这一类里最硬的（登录墙、设备指纹、风控封 IP、App 端加密接口），不是"1 天内跑通"的目标站；
2. 一旦需要住宅代理，代理和算力从你那 80% 里扣，PPE 毛利可能为负；
3. 抓招聘站涉及个人信息，Apify 对 personal data 有政策审查；
4. **0 月活的另一种解释是真的没需求**。Store 主流买家在英文市场，他们不招中国大陆候选人。53 个用户是长期累积，不是月活。saswave 顶着 0% 成功率还在挂 $25 月租，更像是他自己也放弃维护了。

**替代主张：第一个 Actor 打英文长尾、免登录、结构简单的站**（区域招聘板、垂直目录、SaaS/行业名录、协会会员表、展会名单、政府公开数据）。Grok 自己引用的 Welcome to the Jungle 卖得比 LinkedIn 好，就是这个方向的证据。BOSS 直聘放候选池底部，不当第一个。

### 6.2 选词硬筛加第 5 条

原四条没有把"技术可达"量化。加：**目标站必须在无登录、无代理、单 IP 条件下跑通，否则淘汰**。这条是把"1 天内能跑通"和 PPE 毛利同时锁住的唯一硬约束。

### 6.3 14 天验收指标"≥5 个陌生人 run"太软

免费额度会让"有人跑"和"有人付"完全脱钩，5 个 run 可能对应 $0。改成双指标：**≥5 个陌生 run，且 ≥1 笔非零结算**（哪怕 $0.01）。第一笔非零结算才是这条线成立的最小证据。

### 6.4 ¥98 意向测试：把"愿意先付"改成"当场收到钱"

"当场愿意先付"在熟人样本里通过率虚高。改成**真的用微信收 ¥98（或 ¥49 早鸟）**，收不到就记 0。

另外把冻结写死：**14 天内即使 5 个人全付了，也不解冻工程。** 5 个熟人证明不了 PMF，只证明可以继续用个人时间维护；解冻会立刻吃掉 Apify 的时间。付了的人先记账排队，14 天后连同 Apify 的结果一起复盘。
