## 1. 为什么是这个产品

股票方向还有得做，但不是「再做一个行情 App」。到价提醒、自选看板、K 线，同花顺 / 东财 / 富途 / 券商已经免费做完，而且是云端推送 + 短信。

能收费的缝只有一条：上班族要到价、又不能亮炒股软件。来电伪装几乎没人做成产品。

**监控类工具的付费理由从来不是功能多，而是「我不在的时候它还在」。** 现有代码已经写了约 90%（规则、区内只响一次、Bark `call=1`、东财报价源）。差的 10% 是纯工程：把轮询从浏览器搬到 Worker。

### 为什么不新开一条线

| 选项 | 为什么现在不做 |
| --- | --- |
| 朋友的 Apify 模式 | 截图已见：上月起铺了 17 个 Actor，付费的只有 3 个，账面约 **$19.56 + $6.32 + $1.11**。他自己说「做多、有问题就修、AI 不会营销」。平台最热的是 Google Maps（52.8 万用户）、Instagram（34.2 万）、TikTok Clockworks（22.5 万）。抄他的 `tiktok-influencer-finder` 再定价更低，是在巨头 Actor 底下抢 $1。10 个持仓朋友收 ¥98，已经比这张收益表大。 |
| 《谨言》 | 内容产品，靠流量和持续更新，和现有代码零复用。 |
| AI 圆桌 / T-007 | 误读进来的功能。没人会为「几个 AI 讨论了一下」付钱。 |
| GitHub 高星 / OpenStock | 1.4 万星宣称永远免费。星标和现金没有通路。 |

朋友让 AI 巡查「这个平台上什么最火」。2026-07 商店用户数：Google Maps 52.8 万、Instagram 34.2 万、TikTok 22.5 万、Instagram Profile 18.1 万、Google Search 15.7 万。TikTok influencer finder 一类已经有 coregent（约 $2–2.4/千条）、Apify 官方 Agent（$100/千人）和一堆 0 评克隆。出租模式 2026-10-01 退市，之后只剩按次收费、开发者拿 80% 再扣平台成本。最热的类目需求最大，也因此没有你的位置。

## 4. 我们现在有什么、缺什么

正式站：https://coohhh2408-web.github.io/stock-monitor/ （2026-08-21 构建仍可打开）

已经有、且巨头不愿做成这样的：

- 来电掩护到价（接听才看到股价）
- 区内只响一次（`src/lib/alertNotify.ts` 边沿触发），避免同花顺式刷屏
- 判定内核已是纯函数：`alertUtils.ts` / `alertNotify.ts` / `marketHours.ts`
- 习惯市盈率带 + 八道关（未知 ≠ 不通过）——留存用，不进定价页
- 做 T 改成本
- Bark 通道已写在 `notificationService`（`api.day.app`，`call=1`）
- 东财 REST 报价源服务端可直接 fetch，不受浏览器 CORS 限制
- `supabase/schema.sql` 已有 `sync_rooms`（同步码 + 客户端加密），规则上云不用从零建存储

**致命缺口（已核对代码，不是猜测）：**

Bark 从浏览器 `AppStore` 的 `useEffect` / `setInterval` 触发。页面关掉或手机锁屏 = 不轮询、不推 Bark。没有云端盯盘。对用户说「锁屏也能响」而网页关了就不响 = 欺诈。

还不能收费的其它洞：

- 网页定型后没有收银台（20 人以内用收款码 + 激活码即可，不要自建订阅）
- 没有系统推送 / 后台刷新（README 写明没做；第一批用 Bark，不上 App Store）
- 研究对照仍有第一人称大师口吻（会打穿「能复核」的信任，但不是第一笔钱的阻塞项）
- GitHub 0 星，没有获客页——获客不靠星，靠 15 个朋友一对一

## 6. 收费前必须先做的最小工程（按这个顺序）

前一步不通，不做下一步。Cloud Agent 没有 Xcode；Worker 和网页这边能做。

1. **盯盘内核给 Worker 复用。** `alertUtils` / `alertNotify` / `marketHours` 抽掉任何残留 DOM 依赖，补单测。网页和 Worker 跑**同一份**判定——两份逻辑必然漂移，漂移就是漏报。
2. **Cloudflare Worker cron。** 交易时段约每分钟拉东财 `ulist.np` → 跑第 1 步内核 → 命中则 GET `api.day.app` 带 `call=1`。必须按规则按日去重 + 静默窗口，否则横盘会连响。**第 1 天先从 Worker 打一次东财：** 海外 IP 若限流，退到 `qt.gtimg.cn`；两个都不通，改国内小机器跑同一套 cron，方案不变只换执行位置。
3. **规则上云。** 复用已有 `sync_rooms` / `cloudSyncService` 存 alert rules、Bark key、到期日。网页加「云端盯盘」开关。不要新建认证体系。
4. **让用户能验证他买的东西在工作。** 顶栏「云端盯盘 · 最近心跳 hh:mm」；Worker 每个交易日开盘推一条「今天在盯 N 只」。没有心跳，没触发的月份里用户分不清「没到价」和「收了钱没干活」。
5. **收款。** 微信 / 支付宝收款码 + 手工发激活码；Supabase 加一张不超过 20 行的 `licenses` 表。20 人以内一个人 5 分钟。已有微信小商店或知识星球就直接用，不要为此写支付代码。

未做完 1–4，**不准收款**。

## 7. 30 天目标（可执行）

起始：现金 ¥0，付费 0 人。主路线：**云端来电到价，不扩行情。**

从「Worker 在你自己手机上连续 3 个交易日 0 漏报」那天起算 30 天（不是从写文档那天起算）：

| 指标 | 目标 | 怎么数 |
| --- | --- | --- |
| 一对一触达 | **15** | 微信语音或当面，看着你锁屏然后手机响 |
| 付费客户 | **10** | 实付 ¥98 或 ¥128 的人数 |
| 现金 | **约 ¥980** | 10 × ¥98；不换算成 MRR |
| 第 10 天 | Worker 跑通 | 你自己连续 3 个交易日 0 漏报 |
| 第 20 天 | **≥ 4 人付费** | 不够则提前看停手 |

获客只有一条路：**一对一**。不群发、不发朋友圈当投放、不建群。15 次对话就是全部市场活动。

辅助（有余力才做，不做也不停）：

- 15 秒演示：股价到了 → 来电界面 → 接听才看到价。链 `https://coohhh2408-web.github.io/stock-monitor/?mobile=1#push`
- 一篇只讲公式的雪球帖（习惯买点公式）。点名股票一律回「本页不荐股」。这是清单的获客，不是云端闹钟的获客。

每周五只看三个数：自己手机有没有漏报、一对一聊了几人、实付人数。其它指标不看。

未到 10 人付费：不开发新 Tab、不上选股新策略、不改止盈止损公式、不上 App Store。
