## 1. 这个平台到底怎么赚钱

买家不是散户。是营销、招聘、增长、研究团队。他们已经在 Apify 上充过钱或领了免费额度，需要某个网站的结构化数据时，会搜 `BOSS Zhipin scraper`、`Welcome to the Jungle scraper` 这类词。

钱怎么走：你给 Actor 标 Pay-per-event（按条/按事件）。用户跑一次，Apify 记账，你拿约 80%，再减去这次跑的算力。商店标价大多 **$1–10 / 千条**。出租月费 2026-10-01 退市，新 Actor 不要做出租。

冷启动靠货架，不靠你的微信：

- Store 搜索排序
- Actor 详情页吃 Google（有人 24–48 小时排上新词）
- README 前十秒必须让买家看懂「我拿什么数据、用来干什么」
- 默认输入一点 Run 就要出结果
- 当天回 issue（资料上买家会看响应时间）

和独立 App 的差别：这里你租的是**已有流量、已有收银台、已有信任**的货架。产品上架才是起点；但起点已经有人来逛。自己做 App，产品做完才开始找人。

官方量级：每月付给开发者约 **$1.4M / ~3000 人**，人均约 $470，极度右偏。头部过万美元；多数组合在几十到几百美元。3 个月一个小众 Actor ~$200/月是真实中位故事，不是神话。

「98 个 Actor / 6 个月」作者写过：不要去打 LinkedIn / Indeed / Amazon / Instagram / TikTok（每站 5–15 个竞品，含官方）。要找 **有搜索、没好货** 的词。区域招聘板 Welcome to the Jungle 比他做的 LinkedIn 还卖得好。

朋友 17 个 Actor、3 个进账、约 $27：说明**货架上真的有人付钱**，也说明他押的三个词（TikTok / IG）已经被占。不是平台不行，是选词错了。

## 2. 到价提醒：谁买单、冷启动、能不能上架

**谁买单：** 有 A 股持仓、工作日不能亮同花顺的人。卖「锁屏也会以来电样式响」，不卖荐股。

**冷启动弱在四处（不再用 15 个朋友糊弄）：**

1. 没有自带搜索入口。没人搜「来电伪装股价提醒」；搜「股价预警」的人被同花顺/券商吸走。
2. 熟人名单有终点。第 16 个客户从哪来，上一版没有答案。
3. ¥98 是人情价，证明的是「朋友愿意支持」，不是陌生人 PMF。
4. 一对一获客成本不下降。排到第一的关键词边际获客才接近 0。

**能不能放到 Apify：** 技术上能写一个盯东财、推 webhook 的 Actor。商业上是错货架。买家不对、计费方式和「经常不响」相反、来电伪装带不过去、没人在 Store 搜 price alert。能上架的只有原料（行情抓取），那是另一个产品。

所以：到价提醒有产品、没渠道。Apify 有渠道、缺的是选对的产品。14 天补能补的那边。

## 3. 14 天执行（只这一条线）

### 不做

TikTok、Instagram、Amazon、Indeed、Google Maps、LinkedIn；不抄朋友四个 Actor；不靠更低价抢已占的词；不铺 17 个；小红书 / 闲鱼 / 贝壳 / 微博 / B 站已有 SIÁN 等工厂在做，不当第一个。

### 选词四条硬筛（全过才写代码）

1. Store 该词结果 ≤ 3 个，且没有官方、没有 >1 万用户的 Actor
2. 现有结果里至少一半陈旧（久未更新 / 失败率高 / 差评）
3. Google 上该词有真实商业结果（证明有人搜）
4. 目标站尽量免登录、1 天内能跑通；反爬过重则淘汰

### 已巡查（第一轮，未完成 15 词）

| 词 | Store 供给 | 筛 | 备注 |
| --- | --- | --- | --- |
| TikTok scraper / influencer finder | Clockworks 22 万+；朋友也在这 | 淘汰 | 最火 ≠ 你的机会 |
| 小红书 / 闲鱼 / 贝壳链家 / 微博 / B 站 | SIÁN 等已占 | 淘汰 | 工厂级维护 |
| BOSS 直聘 | [saswave](https://apify.com/saswave/boss-zhipin-scraper)：53 用户、**0 月活、成功率 0%、1 星、还在收月租 $25** | **候选** | 有人搜过、货是坏的。反爬很重，第 4 条必须先打通再上架 |

D1–D3 继续把表扩到 ≥15 词。**0 个通过四条 → 扩英文区域招聘板再筛；仍 0 个 → Apify 线也不成立，回到到价提醒。**

第一个通过四条的词就是第一个 Actor，数据定，不拍脑袋。

### 上架标准

- 只做 PPE，README 当销售页：用例 → 样例 JSON → 字段表 → 限制 → FAQ → 配置放最后
- D8：Google 搜该词，自己的 Actor 页在不在结果里
- D9–D14：同族第 2 个词，复用骨架
- **没到 5 个陌生 run：换词，不铺量**

需要 SS 准备：Apify 账号 + 收款资料（商店才能结款）。没有账号，Actor 写完也上不了架。
