# 到价提醒：可执行商业计划（2026-08-27）

数据仅供参考，不构成投资建议。本计划卖的是纪律工具，不是荐股。

## 结论（先看这 4 行）

1. **股票方向还有得做，但不是「再做一个行情 App」。** 到价提醒、自选看板、K 线，同花顺 / 东财 / 富途 / 券商已经免费做完，而且是云端推送 + 短信。
2. **能收费的缝只有一条：** 上班族要到价、又不能亮炒股软件；同时要一个**能复核数字**的买点纪律，不要大师口吻。
3. **GitHub 上做得热闹的，几乎都不赚钱。** 高星是开源看板或 AI 研报玩具；中文仓库几十星，自用、Telegram、伪装桌面，没有收银台。
4. **下个月不扩功能。** 把已有的来电掩护 + Bark + 习惯买点清单收成能收款的一页，先验证有人付钱。

## 2. 竞品（Google）

做得好、有用户的，都是巨头或券商。独立产品几乎看不见收银台。

| 产品 | 到价怎么做 | 收费 | 对你意味着什么 |
| --- | --- | --- | --- |
| 同花顺 | 个股铃铛、智能预警、可短信 | 金牛会员约 ¥6–8/月；Level-2 / 诊股另售 | 提醒本身几乎免费获客；别跟它比功能清单 |
| 东方财富 | 自选预警，基础面大量免费 | 高阶少、靠开户 | 资讯和免费是它的场，不要进 |
| 雪球 | 自选长按价格提醒 | 社区为主，VIP 解锁部分实时 | 适合发「公式怎么算」，不适合当下载竞品 |
| 富途牛牛 | 到价 / 盘口 / 指标 / 事件，可设频率 | 开户交易抽佣 | 港美股用户会装它；你的缝仍是 A 股上班族隐蔽 |
| 华泰涨乐 / 广发等券商 | **云端**预警，锁屏也推，可挂短信/微信 | 提醒免费，靠佣金 | 这是「到价」的真正对手。你没有云端推送就还没资格收费 |
| GuruFocus | 公允价值、PE 历史、机构持仓 | 约 $549/年 | 证明「可核对估值」有人付钱；贵、偏美股，不是你的客户 |
| Seeking Alpha / Koyfin | 研报、图表、提醒 | $25–80/月档 | 英文研究平台；不要做成中文山寨 |
| TradingView | 条件预警（免费档限额） | 订阅解锁条数 | 技术指标预警，不是买点纪律 |

Google 上「哪些软件有股价预警」的答案清一色是：装同花顺或券商 App。独立开发者没有出现在这个问答里。

## 4. 我们现在有什么、缺什么

正式站：https://coohhh2408-web.github.io/stock-monitor/ （2026-08-21 构建仍可打开）

已经有、且巨头不愿做成这样的：

- 来电掩护到价（接听才看到股价）
- 区内只响一次，避免同花顺式刷屏
- 习惯市盈率带 + 八道关（未知 ≠ 不通过）
- 做 T 改成本
- Bark 通道已经写在 `notificationService`（可做「锁屏也能响」的过渡，不必等 App Store 推送）

还不能收费的洞：

- 网页定型后**没有收银台**
- 没有系统推送 / 后台刷新（README 写明没做）
- 研究对照仍有第一人称大师口吻、代码碰撞等越界（会打穿「能复核才收费」）
- GitHub 0 星，没有获客页，只有仓库 README

## 5. 卖给谁、卖什么、多少钱

**客户：** 有 A 股持仓、工作日白天不能亮炒股 App 的人。不是短线打板，不是要 Level-2 的人。

**卖：**

1. 到价时手机像来电，不像行情软件（主因）
2. 习惯买点带 + 八道关，公式写在界面上（留存）
3. 做 T 记一笔就改成本（加价理由，不是获客钩子）

**不卖：** 荐股、巴菲特说买、资讯量、全市场选股池。

**价格：** ¥39 / 月，或 ¥299 / 年（约 7.7 折）。对标同花顺金牛太便宜、对标 GuruFocus 太贵。¥39 是「少点一次外卖、办公室少被看一眼」。

**交付（最小收费闭环，按这个顺序）：**

1. 修研究对照越界（第一人称、代码撞名、无市盈率仍报价）——否则不能收「可核对」的钱
2. 设置里把 Bark 做成「付费后锁屏提醒」的默认路径（已有代码）
3. 一页收银台：Lemon Squeezy / 爱发电 / 微信收款码择一，先不要自建订阅系统
4. 正式站顶上一句：上班到价会伪装成来电；演示链 `?mobile=1#push`

未做 App Store 推送之前，**用 Bark 收第一批钱**。等 12 个付费再谈壳。

### 3 条获客动作（只做这三条）

1. **一条演示，三个帖。** 录 15 秒：股价到了 → 来电界面 → 接听才看到价。发 V2EX（分享创造）、即刻、小红书。标题只用「上班到价别亮同花顺」，正文放 `https://coohhh2408-web.github.io/stock-monitor/?mobile=1#push`。不发 GitHub，不谈巴菲特。
2. **10 个真实持仓朋友。** 微信一对一：帮他加自选、设一个真正会到的价、装 Bark。7 天后收款 ¥39。拒绝「先免费用三个月」。
3. **一篇只讲公式的雪球帖。** 题目：「习惯买点 = 现价 ×（行业习惯市盈率 ÷ 当前市盈率）」。贴清单截图，评论区只解释公式和「未知怎么标」，点名股票一律回「本页不荐股」。链到个股清单，不链选股排行。

每周五只看三个数：演示打开、Bark 试推成功、实付人数。其它指标不看。
