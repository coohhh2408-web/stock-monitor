# 财报解读 Skill

收费卖的是**同一组报表数字的三种读法**，不是「巴菲特帮你读年报」。

可执行实现：`src/services/financialsApi.ts`、`src/services/earningsBrief.ts`。数字用代码算，不要用模型心算。

## 开源 skill 学什么

| 来源 | 学 | 不用 |
|---|---|---|
| `xbtlin/ai-berkshire` `earnings-review` | 资料可得性分级；经营现金流 vs 净利；杠杆与应收/存货红旗；第三方汇总必须标明 | 读 10-K 原文、电话会语气、附注挖掘、给出加仓减仓 |
| `yennanliu/InvestSkill` `financial-report-analyst` | 先财务报表后叙事；YoY 对照；会计质量红旗 | 没有原文时做 MD&A 深读 |
| `HHFinAi/earnings-analysis` | 一页纸：Parse / Compare / Diagnose | 卖方 beat/miss 和共识预期（我们没有一致预期） |

本产品当前是 **B 级资料**：东方财富 datacenter / 同花顺三表 / F10 主要指标，不是巨潮/SEC 原文。按 C/B 级执行：只解读核心财务变化，跳过附注和电话会。

## 数据

打开个股详情时按瀑布拉最新报告期；披露日期和报告期必须展示。GitHub 取数 skill 只当端点地图，不跟登录爬雪球。

- 主源：东方财富 datacenter（A/港/美，浏览器可直连）
- A 股备源：同花顺 `_benefit` / `_cash` / `_debt`
- 开发环境最后一档：emweb F10（`ZYZBAjaxNew` / `GetZYZB`）
- 美股 datacenter 常无经营现金流 → Q5 保持未知；有资产负债率/流动比率则 Q6 可核对
- 与盘口同一只股票

## 质量关（写回价值清单）

- **赚钱质量**：经营现金流 ÷ 净利。≥80% 成立；&lt;80% 未过关；对不上就未知。
- **负债安全**：资产负债率 + 流动比率，有则加上利息覆盖。金融股不硬套。≥70%、流动比率 &lt;1 或利息覆盖 &lt;2 未过关；低杠杆成立；中间档无覆盖则未知。
- **管理层**：没有原文就未知。利润与现金背离只作为芒格框架红旗，不升格成诚信否决。

## 输出（财报页）

```
## 结论
一句话：现金是否跟上利润 / 是否利润好看现金落后

## 本期数字
营收、净利、同比、经营现金流/净利、毛利率、净利率、ROE、资产负债率、流动比率

## 三种框架
巴菲特：业主收益、现金、杠杆
芒格：倒过来想，红旗清单
段永平：是不是对的生意；对的价格另算

## 边界
第三方汇总，不是原文；不是投顾
```

## 硬禁令

1. 不写「我是巴菲特，我读了年报」。
2. 不把 datacenter / 同花顺 / F10 说成巨潮原文或 10-K。
3. 没有一致预期就不说超预期/低于预期。
4. 不从财报页输出仓位百分比。
