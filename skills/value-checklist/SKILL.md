# 价值清单 Skill

收费卖的是**可核对的纪律工具**，不是荐股，也不是「巴菲特说买」。

本 skill 管三件事：什么数据能用、八道关怎么判、界面必须输出什么。计算在 TypeScript 里完成（`src/services/valueSkill.ts` + `src/services/valueChecklist.ts`），不要用模型心算。

## 他们怎么写，我们改什么

两份高星 GitHub skill 的**写法**几乎一样，值得学的是结构，不是人设。

| 写法 | `agi-now/buffett-skills` | `xbtlin/ai-berkshire` | 咱们 |
|---|---|---|---|
| 触发 | YAML `description` 写很长，没点名也触发 | 研究 playbook，按模块执行 | 价值清单 / 习惯买点就触发 |
| 先筛 | 2 分钟 8 问，4 个 No 就过 | A/B/C 信息级，缺资料不准装完整 | 八道关；**未知 ≠ 不通过** |
| 展开 | SKILL.md 常驻，`references/` 按需读 | 双源数据 + Python 验算，禁止 LLM 心算 | 盘口算买点；F10 最新报告期答质量关 |
| 输出 | 固定模板：结论 / 能力圈 / 假设 / 买价 / 卖点 | 强制 通过/灰色/不通过；空仓 vs 持仓分开 | 结论 + 习惯买点 + 公式 + 八道关 + 三种宽严 |
| 人设 | 「用巴菲特的口吻」 | 四大师模拟点评 | **禁止第一人称大师** |
| 停手 | 能力圈外就停 | 没双源、工具验算失败就打回 | 无市盈率不报价；未知超过 4 项只报价、不当研究结论 |

细则见 `references/attribution.md`。不要把本产品说成「微调了 GitHub 上的巴菲特模型」。

## 硬禁令

1. 不写「我是巴菲特/芒格/段永平」。
2. 不把三人姓名当成持仓或荐股背书；他们只是同一公式的三种宽严标签。
3. 盘口没有市盈率 → 习惯买点为「—」，不许推一个「合理价」。
4. 不准用模型心算 DCF、ROE、自由现金流；没有对应财报字段就标 **未知**。
5. 不准输出资产仓位百分比当投顾（「建议买 10%」）。研究对照里的仓位是框架对照，默认 ToC 不展示。
6. 信息级最高只到 **B**。没有年报双源，永远不要标 A。
7. 未知项不得用「合理推测」填成成立。

## 数据合同

只读当前这只股票的盘口和最新报告期，字段以 `references/data-contract.md` 为准。

当前能用的：盘口 `name`、`code`、`market`、`price`、`industry`、`pe` / `peTtm`；打开详情后同步的最新报告期（营收、净利、经营现金流、资产负债率等）。

没有的（必须标未知）：年报原文、电话会、利息覆盖、管理层诚信、第二数据源。

生意类型用名称/行业关键词归类（`inferBusinessKind`），这是启发式，不是年报阅读。

## 两分钟八道关

问题极性已改成 **成立 = 好事**，降低误读。完整表见 `references/eight-gates.md`。

先跑这 8 问。规则：

- **未知 ≠ 不通过。** 没有证据就写未知。
- 未知 ≥ 4 → 信息 **C** 级：可以算习惯买点，文案必须写「只能算估值习惯，不能当研究结论」。
- 质量关（1–7）里「未过关」≥ 4，或标的是期货 → 清单不适用，不报价。
- 第 7 问（管理层是否直面问题）是一票否决：**只有证据为「未过关」才否决**；没有证据就是未知，不得虚构否决。
- 有产品内置说明的少数名字（茅台、AAPL 等）最多升到 **B** 级：Q1–Q4 可以引用内置说明，且必须标明「产品内置，非正式财务模型」。
- 同步到最新报告期后，Q5/Q6 用公式回答；Q7 在没有原文时仍为未知。
- 只有盘口、没有财报时，Q5/Q6 保持未知。

## 习惯买点（唯一准出的数字）

```
习惯买点 = 现价 ×（该生意类型的习惯市盈率 ÷ 当前市盈率）
```

- 习惯市盈率来自 `PE_BAND`，按生意类型，不是大师原话。
- 巴菲特 / 芒格 / 段永平三个数字 = 同一公式 × 不同 `peBias`（宽 / 中 / 严）。
- 当前市盈率必须与个股页盘口同一路；对不上就先不报价。

## 标准输出（默认 ToC，不可缺）

对应界面「价值清单」卡，不要写成研报。

```
## 结论
进入习惯买点带 / 未到习惯买点 / 不适用 / 先不报价
一句话原因（倍数到了 ≠ 该买）

## 习惯买点
数字 · 现价 · 相对现价百分比
公式：现价 ×（习惯市盈率 ÷ 当前市盈率）

## 计算关
生意类型 / 估值 / 习惯买点 / 数据 / 最新财报

## 八道关
每问：成立 | 未过关 | 未知 + 一句依据
信息级：B 或 C（禁止 A）
未知计数

## 三种习惯买点
同一公式的宽/中/严，标签可以叫巴菲特/芒格/段永平，但必须写明只是宽严

## 依据与边界
数据源、公式、不是内在价值、不是投顾
```

研究对照（三人短评 / 打分清单）不是默认。若用户点进去，仍须带依据与边界，且不得把打分说成大师本人。

## 改代码时

1. 先改 `src/services/valueSkill.ts` 的关卡规则，再改文案。
2. 数字变化必须能在界面「依据与边界」里解释。
3. 新增数据源必须先改 `references/data-contract.md`，再写取值代码。
4. 不要为了「看起来完整」给没有字段的关卡填成立。Q7 在没有原文时必须未知。
