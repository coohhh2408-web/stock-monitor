# 数据合同

价值清单只消费当前打开的 `QuoteItem`。没有的字段就停，不准补。

## 现在有

| 字段 | 用途 | 没有时 |
|---|---|---|
| `name` `code` `market` | 展示、匹配内置说明 | 不分析 |
| `price` | 习惯买点公式的现价 | 不报价 |
| `industry` | 辅助 `inferBusinessKind` | 只靠名称 |
| `pe` 或 `peTtm` | 当前市盈率 | 结论改为「先不报价」 |

市盈率必须与个股页 `QuoteStatsGrid` 同一路盘口（东方财富 / 腾讯财经行情链路）。清单不得另取一套 PE。

## 现在没有（一律未知）

- 年报、10-K、股东信
- 自由现金流、业主收益、ROIC/ROE、毛利率
- 总负债、净现金、最差情景偿债
- 管理层诚信、减持、资本配置记录
- 护城河的可检验证据（提价记录、份额、转换成本）
- 第二独立数据源（因此信息级不能标 A）

## 生意类型

`inferBusinessKind(name + industry)` 是关键词启发式。输出可以写「暂归为消费特许经营权」，不能写「已读年报，确认是特许经营权」。

期货（`market === 'futures'`）不是企业，整张清单不适用。

## 升级路径（C → B → A）

- **C**：只有盘口。默认绝大多数标的。
- **B**：盘口 + 产品内置的一句话生意说明（白名单名字）。仍无财报。
- **A**：至少两个独立来源的财报数字，且用代码验算。本产品尚未具备，禁止自称。
